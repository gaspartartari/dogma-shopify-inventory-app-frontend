# Dogma Inventory Sync - Frontend

Vite + React + TypeScript app using TailwindCSS and AG Grid.

### Scripts

```bash
yarn dev       # start dev server
yarn build     # build for production
yarn preview   # preview local build
```

### TailwindCSS

- Config: `tailwind.config.js`
- Directives are in `src/index.css` via `@import "tailwindcss";` (v4)

### AG Grid

- Packages: `ag-grid-community`, `ag-grid-react`
- Example usage in `src/App.tsx`

### Notes

- Requires Node 18+.
